🕸️ 贡献方式一：捐赠服务器至 EasyTier（公共共享节点）

        

          把你的公网服务器变成 EasyTier 的公共共享节点，所有没有公网 IP 的用户都能借它组网、联机。
          官方设计上，不带任何参数启动 easytier-core 即为公共共享节点（不需要 root 权限），门槛极低。
          贡献后请提交 issue 登记，即可领取捐赠令牌成为贡献者 ⭐
        


        

          ① 准备一台公网服务器
          
Linux（推荐 Debian/Ubuntu）或 Windows 均可，1 核 1G、按流量计费的小机器就够用。EasyTier 是去中心化的，节点之间会对等转发。

        


        

          ② 安装 EasyTier 并启动共享节点
          

            下载对应平台的发行包（GitHub Releases /
            官网下载页），解压后执行：
          

          
# 不带参数启动 = 公共共享节点（无需 root、无需配置网络名/密钥）
./easytier-core

          
默认监听 TCP/UDP 11010、WG 11011、QUIC 11012、FakeTCP 11013，记得在安全组/防火墙放行这些端口。

        


        

          ③ 配置开机自启（Linux systemd）
          

            公共节点的 fd 消耗较大，务必设置 LimitNOFILE，否则会因文件描述符耗尽而拒绝服务：
          

          
sudo tee /etc/systemd/system/easytier.service > /dev/null <<'EOF'
[Unit]
Description=EasyTier Public Shared Node
After=network.target syslog.target
Wants=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/easytier-core
Restart=always
RestartSec=3
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now easytier

        


        

          ④ 建议：配置 fail2ban 挡掉无效连接（可选但强烈推荐）
          

            公共节点会被大量连不上的客户端反复重试，日志形如
            wait handshake timeout。用 fail2ban 自动封禁可显著降低连接数、提升服务质量：
          

          
# 安装并启用
sudo apt install -y fail2ban && sudo systemctl enable --now fail2ban   # Debian/Ubuntu

# 日志过滤器
sudo tee /etc/fail2ban/filter.d/easytier.conf > /dev/null <<'EOF'
[Definition]
failregex = remote: \S+://:\d+, err: wait resp error:.+
EOF

# 封禁策略：10 分钟内失败 3 次，封 1 小时
sudo tee /etc/fail2ban/jail.local > /dev/null <<'EOF'
[easytier]
enabled  = true
filter   = easytier
backend  = systemd
journalmatch = '_SYSTEMD_UNIT=easytier.service'
maxretry = 3
bantime  = 3600
findtime = 600
banaction = nftables-multiport
EOF

sudo fail2ban-client reload
sudo fail2ban-client status easytier   # 查看已封禁列表

        


        

          ⑤ 进阶选项（按需）
          

            · 只帮别人打洞、不转发流量：easytier-core --relay-network-whitelist --relay-all-peer-rpc

            · 只服务自己的网络（不做公共节点）：easytier-core --private-mode true --network-name 你的网络 --network-secret 你的密钥

            · 限定只转发某些网络：--relay-network-whitelist "ab* abc"
